# Beta 20

- Mac transfer progress appears only while photo or video data is being sent. Waiting for system scheduling and receiver confirmation keep their text status without an empty or full progress bar.
- Apple senders can find a paired receiver when iOS or macOS reports Wi-Fi and cellular interfaces together. Transfers remain restricted to the local network.
- iOS source builds add an optional setting to keep the screen awake during foreground backup work. It turns off automatically when backup is paused or finishes, the receiver becomes unavailable, or the app leaves the foreground.

Mac requires Apple Silicon and macOS 14+. Android requires arm64 and Android 10+.
iOS 17+ is available from source. Receiver delivery and cloud backup remain separate states.
